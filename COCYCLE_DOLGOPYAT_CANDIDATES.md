# Candidate IFS / cocycle structures for Syracuse μ_n

For each candidate, check against ARHW hypotheses verbatim from `COCYCLE_DOLGOPYAT_HYPOTHESES.md`:
- (H1) IFS on compact interval I ⊆ R, finite, every f_i differentiable.
- (H2) Uniformly contracting: 0 < inf|f'| ≤ sup|f'| < 1.
- (H3) C^r with r ≥ 2 (so f''_i exists on K_Φ).
- (H4) Non-linearity: NOT C² conjugate to linear (equivalently: cocycle UNI holds; equivalently: ∃ f ∈ Φ with f''(x) ≠ 0 for some x ∈ K_Φ up to conjugation).
- (H5) Derivative cocycle c(I,x) = −log|f'_I(x)| is the right cocycle.

## Candidate (a): Base-3 expansion IFS Φ_3 = {x → (x+a)/3 : a ∈ {0,1,2}} on [0,1]

Maps: f_0(x) = x/3, f_1(x) = (x+1)/3, f_2(x) = (x+2)/3.

| Hypothesis | Check |
|---|---|
| H1 — IFS on [0,1] | YES, three strict contractions of [0,1]. |
| H2 — Uniformly contracting | YES, |f'_a(x)| = 1/3 identically. |
| H3 — C^r, r ≥ 2 | YES, in fact C^ω (affine). |
| H4 — Non-conjugate to linear | **NO.** f''_a(x) = 0 identically. By the paper's own definition (p. 2, "Ψ is linear if g''(x) = 0 for every x ∈ K_Ψ and g ∈ Ψ"), Φ_3 IS linear. And since Φ_3 is C^ω and linear, by paper p. 2 ("if Ψ is C^ω(R) and linear then it must be self-similar"), Φ_3 is self-similar — which it manifestly is (affine maps with common derivative 1/3). |
| H5 — Derivative cocycle | Degenerate: c(I,x) = −log(1/3)^{|I|} = |I| log 3, constant in x. Cocycle has no x-dependence at all. UNI fails trivially: d/dx(log f'_ξ − log f'_ζ) ≡ 0 for all ξ,ζ, contradicting Claim 2.2. |

Self-conformal measure is Lebesgue on [0,1] (the unique self-similar measure with weights (1/3, 1/3, 1/3) on a self-similar IFS satisfying OSC). With non-uniform weights (p_0, p_1, p_2) you get a Bernoulli-like measure on the same attractor [0,1].

**Verdict: framework EXCLUDES this case explicitly.** Φ_3 is the prototype of a linear self-similar IFS — ARHW's whole point is that polynomial Fourier decay is NOT automatic in this regime (Bernoulli convolutions for Pisot numbers are the classical obstruction; see paper p. 3 final paragraph).

## Candidate (b): Base-3 with Syracuse-twisted contractions

φ_a(x) = (x + a + δ_a(x))/3 where δ_a is a small smooth perturbation reflecting parity-dependent Syracuse updates (e.g., δ_a depending on residue class of position mod 3).

| Hypothesis | Check |
|---|---|
| H1 | YES if δ_a chosen so φ_a maps [0,1] → [0,1] and stays a contraction. |
| H2 | Conditional: need |1/3 + δ'_a(x)/3| ∈ (c, 1) for some c > 0. Achievable for small smooth δ_a. |
| H3 | Conditional: need δ_a ∈ C² ([0,1]). Constructible. |
| H4 | Conditional: need δ''_a(x) ≠ 0 on K_Φ for some a, AND not removable by C² conjugation. **This is where the issue lives.** |
| H5 | Cocycle becomes c(I,x) = −log|(1+δ'_I(x))/3|, x-dependent if δ'_a ≠ const. |

**The structural problem:** Syracuse dynamics is intrinsically arithmetic — the map n → (3n+1)/2 (when n odd) and n → n/2 (when n even) is defined on integers, lifted to ℤ_3 or ℤ_2 by p-adic completion. There is no canonical δ_a derived from Syracuse that lives on ℝ smoothly; any choice of δ_a is **ad hoc** — it is not derived from Syracuse but bolted on so that the framework's hypothesis fires.

Even if a δ_a is constructed making the IFS non-conjugate-to-linear, the self-conformal measure ν of the twisted IFS is a measure on [0,1] with **no canonical relation to μ_n on ℤ_3**. The construction would satisfy ARHW hypotheses but the resulting Fourier decay would be on ν, on the wrong space, with no mechanism transferring back. See Transfer doc.

**Verdict: constructible in form, but NOT a natural Syracuse object. Self-conformal ν has no canonical link to μ_n.**

## Candidate (c): Cocycle over Syracuse symbolic dynamics

Syracuse's parity sequence gives a symbolic shift σ : {0,1}^ℕ → {0,1}^ℕ. Define a cocycle A : {0,1}^ℕ → G (some group) by Syracuse's update.

| Hypothesis | Check |
|---|---|
| H1 — IFS of strict contractions of compact I ⊆ R | **NO.** ARHW requires an IFS Φ = {f_1,...,f_n} of smooth contractions of an interval in ℝ. A cocycle over a symbolic shift is NOT an IFS in this sense unless we additionally specify maps f_a on an interval. The symbolic-shift framework alone doesn't activate Thm 1.1. |
| H3 — C² | Not applicable — there are no smooth maps yet. |
| H4 — Derivative cocycle of smooth IFS | The Syracuse cocycle (e.g., n ↦ (3n+1)/2 vs n ↦ n/2) acts on **integers**, not as a smooth-derivative cocycle of IFS contractions on [0,1]. The natural cocycle is multiplicative on ℤ_2/ℤ_3, not the −log|f'| derivative-cocycle of a continuous IFS. |

The paper is explicit (p. 10): "G ... the free semigroup generated by the family {f_a : 1 ≤ a ≤ n}, which acts on [0, 1] by composing the corresponding f_a's. We define the derivative cocycle c : G × [0, 1] → R via c(I, x) = −log|f'_I(x)|." The cocycle's domain is a free semigroup of smooth contractions of [0,1], NOT an arbitrary symbolic-shift cocycle.

**Verdict: Syracuse's symbolic-shift cocycle is structurally a different object. ARHW's hypothesis cannot be activated without first supplying smooth contractions of an interval — which puts us back at candidates (a) or (b).**

**Verdict: the corpus INDEX's claim "T_lead transfer operator is a cocycle case" is an inherited terminology overlap, not a verified structural identification. T_lead is rank-1 (Probe 2), arithmetic, finite-dimensional. ARHW's transfer operator is on infinite-dimensional C¹([0,1]) built from a smooth cocycle.
