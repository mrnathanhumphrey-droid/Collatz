## Result 1: ⟨α_det⟩ = log(6) / log(4/3) — DERIVED

For odd r ∈ [1, 2^k − 1] under the prefix algorithm:
- prefix_steps(r) = k + j(r), where j is the number of "3a" rule applications.
- a_final(r) = 3^(j(r))
- The j-distribution across the 2^(k−1) odd classes is binomial: count of classes with j = i is C(k−1, i−1), so ⟨j⟩ = (k+1)/2 exactly.

Then:
```
⟨α_det⟩ = ⟨prefix_steps⟩ + K_h · ⟨log(a_final / 2^k)⟩
        = (k + ⟨j⟩) + K_h · (⟨j⟩·log 3 − k·log 2)
        = k · (1 − K_h·log 2) + ⟨j⟩ · (1 + K_h·log 3)
```

With K_h = 3/L where L = log(4/3):
- 1 − K_h·log 2 = (L − 3 log 2) / L = (log 4 − log 3 − 3 log 2) / L = **−log 6 / L**
- 1 + K_h·log 3 = (L + 3 log 3) / L = (log 4 + 2 log 3) / L = **2 log 6 / L**

Substituting and simplifying (with ⟨j⟩ = (k+1)/2):
```
⟨α_det⟩ = (log 6 / L) · (−k + (k+1)) = log 6 / log(4/3)
```

**Numerical value:** log(6)/log(4/3) = **6.228263**, *exactly*, independent of k.

**Verification:** Direct computation of α_det(r) over all 2^(k−1) classes at k ∈ {6, 8, 10, 12, 14}:
| k | empirical ⟨α_det⟩ | error vs log(6)/L |
|---|------------------|-------------------|
| 6  | 6.228263 | −5.3e-15 |
| 8  | 6.228263 | −7.1e-15 |
| 10 | 6.228263 | −7.1e-15 |
| 12 | 6.228263 | −8.9e-15 |
| 14 | 6.228263 | −1.1e-14 |

Match is to machine precision at every k. ✓

**Interpretation:** ⟨α_det⟩ is an *exact* invariant of the prefix algebra and the random-walk heuristic. It's a property of the prefix decomposition's construction, not the σ data — there's no Collatz dynamics in this number, only the K_h heuristic and the binomial j-distribution.

## Result 3: Slope ≈ 1/2 on log(threshold) — DERIVED MECHANISM, NOT CLOSED FORM

The TA.3 fit gave ε(f) ≈ −2.35 + 0.486 · log(f). The empirical slope is 0.486, suspiciously close to 1/2.

**Hypothesis tested:** ε(f) − ε(σ) = K_h · ⟨overshoot at f⟩, where overshoot = log(f) − log(v*), v* = orbit value at first-crossing of threshold f. If the slope on log(f) came from overshoot growing with log(f), the decomposition would be exact.

**Empirical test (experiment 39):** at N = 2²⁷, k = 8, walked all 6.7×10⁷ odd trajectories to first-crossing of each of 4 thresholds, recorded v*.

| threshold | log(f)_avg | ⟨log(f/v*)⟩ | predicted from ε(f) decomp |
|-----------|-----------|--------------|-----------------------------|
| N^(2/3) | 11.81 | 0.298 | 0.523 |
| sqrt(N)·log(N) | 11.73 | 0.298 | 0.525 |
| sqrt(N) | 8.86 | 0.298 | 0.442 |
| sqrt(N)/log(N) | 5.98 | 0.301 | 0.345 |

**Mean overshoot is essentially constant at ≈ 0.298 nats across all four thresholds.** Linear fit ⟨overshoot⟩ ≈ 0.303 − 0.0004·log(f). Slope on log(f) is essentially zero.

**Verdict on hypothesis:** RULED OUT. The decomposition `ε(f) − ε(σ) = K_h · ⟨overshoot⟩` is false. Overshoot accounts for K_h · 0.30 ≈ 3.1 Collatz steps (a constant), but ε(f) varies by ~5 nats between thresholds. **The slope on log(f) is not generated by overshoot at first-passage.**

**What is the slope, then?** Re-deriving from data: define R(f) = σ_mean − s_mean(f) (the "rest of σ past first-crossing of f"). Empirically:

R(f) ≈ 9.94 · log(f) − 0.10

If this segment used the asymptotic Tao constant K_h, R(f) would be K_h · log(f) + const = 10.43 · log(f) + const. **Empirically R uses K_eff ≈ 9.94, not K_h.** The slope on log(f) in ε is exactly:

> K_h − K_eff = 10.43 − 9.94 = **0.486** ≈ 1/2

Verified to ≤ 1% precision against TA.3's empirical slope.

**Structural picture:**

| Segment | Effective descent constant |
|---|---|
| N → first-crossing of f | K_h ≈ 10.43 (asymptotic, matches Tao) |
| v* (≈ f) → 1 | K_eff ≈ 9.94 (small-value regime) |

The "below threshold" descent uses a slightly different K because the small-value regime has deterministic orbit structure that the random-walk approximation doesn't fully capture. Tao 2022's leading term `K_h · log(N/x)` is asymptotic for the *whole* descent; per-segment effective constants depend on which range you average over.

**Why K_eff = 9.94 (or 10.11 with cleaner slope)? Trajectory measure ruled OUT.**

Direct test: `K(E[v]) = (1 + E[v]) / (E[v]·log 2 − log 3)`.

| input | E[v] | K |
|---|---|---|
| Geom(1/2) (i.i.d.) | 2.000 | 10.428 (= K_h) |
| Trajectory (q=3, agent 2) | 1.995 | **10.538** |

**Trajectory measure shifts K UP from K_h, not down.** The v=4 / v=10 density spikes are already inside the empirical E[v] = 1.995 (they pull mean v up locally but the global mean still sits below 2 because of the v=6..14 sags). To get K = 9.94 we'd need E[v] = 2.024; to get K = 10.11 we'd need E[v] = 2.016. Both are *above* 2, not below; ruled out empirically.

**Cleaner slope estimate.** The TA.3 fit `gap = a + b · log(f)` used all 5 observables (σ + 4 first-passage). σ is a regime-different observable (it terminates exactly at 1, no overshoot). Refitting on the 4 first-passage observables only:
- TA.3 all 5: slope = 0.456, K_eff = 9.97
- First-passage only: **slope = 0.320, K_eff = 10.11**

The cleaner K_eff is 10.11 (the 9.94 was the TA.3 mixed-fit number).

**Real mechanism: finite-N μ_β oscillation.**

K_eff = 10.11 matches the empirical μ_β = σ̄ / ⟨log n⟩ slope at *finite* N from experiment 26:

| N | μ_β |
|---|---|
| 2²⁰ | 10.372 |
| 2²² | 10.382 |
| 2²³ | 10.384 |
| 2²⁴ | 10.404 |
| 2²⁵ | 10.419 |
| 2²⁷ | 10.429 |

μ_β at small/moderate N is *below* K_h, approaching K_h from below. The descent from v* (≈ first-crossing of f) to 1 traverses log-scale [0, log v*], i.e., the small-to-moderate-value regime where μ_β is below the asymptotic K_h. Hence the **effective K for the below-threshold segment matches the finite-N μ_β at moderate scales, not the trajectory-measure-corrected K**.

**Closed form for K_eff therefore reduces to the open TA.1 question:** characterize μ_β(N) as a function of scale N. The β-oscillation analysis (experiment 26 + 27) is exactly the relevant piece. The 1/2-ish slope on log(f) and the K_eff < K_h gap both trace to the same finite-N descent-rate phenomenon, *not* to the trajectory-measure E[v] correction.

**Status:** the slope's *mechanism* is identified — it's the finite-N effective μ_β at the value scales the orbit traverses below threshold. Its *closed form* requires understanding μ_β(N), which is itself open. The "1/2" round number is approximate; the true value (≈ 0.32 from clean fit, or 0.46 with σ included) matches K_h − ⟨μ_β over relevant range⟩ within reasonable empirical precision.

**No setup yields slope_odd = 9.31.** The empirical slope is highly unstable at small V due to high-leverage σ-records (σ(27)=111, σ(703)=170, σ(6171)=261). Once V ≥ 10⁵, slope stabilizes near K_h = 10.428.

**The halving compensation isn't consistently positive.** At threshold 11,586, slope_all − slope_odd = **−0.18** (negative, not +0.63). The hypothesis's specific decomposition isn't reproducible.

**Verdict:** The proposed K_eff = 9.31 + 0.63 = 9.94 decomposition does not survive empirical contact. K_eff itself is regime-dependent (9.94 with σ included, 10.11 first-passage-only) and the parity decomposition gives different signs and magnitudes at different thresholds.

**What this means for the closed-form program:**

The K_eff value isn't a structural constant of small-value Collatz dynamics in any clean sense. It traces back to the **same finite-N μ_β oscillation finding from TA.1**:
- At the value scales the orbit traverses below threshold (log v ∈ [0, ~9] for f = √N at N = 2²⁷), the empirical μ_β is ~10.37–10.42, below the asymptotic K_h.
- K_eff for "below threshold to 1" descent is the leverage-weighted average of μ_β over those scales, with the specific value depending on the threshold's location.

**Closed-form derivation pathways (both open):**

1. **Solve Lagarias's trajectory-measure invariance.** The trajectory-visit measure π(v) on odd integers under the Syracuse map is conjecturally absolutely continuous w.r.t. natural density (Lagarias's pseudorandomness conjecture), but no closed form for the invariant density exists. This is a 40-year open problem.

2. **Characterize finite-N μ_β(N) directly.** The TA.1 finding shows μ_β oscillates around K_h with amplitude ≈ 0.01 across N ∈ [2²⁰, 2³²]. A closed form for μ_β(N) would supply K_eff for any descent range. This is also open and ties to record-σ class-fraction analysis (compute_threads_findings.md).

Both are open. Neither will be solved as a quick by-product of this project.

## Result 6: K_eff is N-dependent — finite-N mechanism CONFIRMED

**User's discriminator (received 2026-05-02):** if K_eff is stable across N, finite-N is ruled out as the mechanism for the slope on log(threshold). If K_eff drifts with N, finite-N is confirmed.

**Empirical test (experiment 42):** for each parquet at N ∈ {2²⁰, 2²², 2²³, 2²⁴, 2²⁵, 2²⁷}, sampled 100K odd starts, walked each orbit to first-crossing of 4 per-n thresholds {n^(2/3), √n·log n, √n, √n/log n}, fit K_eff = slope of R(f) = σ̄ − s̄(f) on log(f).

| N | K_eff | K_h − K_eff |
|---|---|---|
| 2²⁰ | **11.33** | −0.91 |
| 2²² | 10.33 | +0.10 |
| 2²³ | 10.09 | +0.34 |
| 2²⁴ | **9.98** | +0.45 |
| 2²⁵ | 9.99 | +0.44 |
| 2²⁷ | 10.08 | +0.35 |

K_h = 10.428. Spread = **1.35**. Linear drift coefficient = −0.242 per unit log(N), R² = 0.609.

**Verdict:** K_eff DRIFTS substantially with N. Finite-N mechanism CONFIRMED. K_eff is not a structural constant of small-value Collatz dynamics.

**Shape of the drift.** Non-monotone: very high at small N (11.33 at 2²⁰, *above* K_h), drops to a minimum near 2²⁴ (9.98), rebounds slightly to 10.08 at 2²⁷. This matches the **μ_β oscillation pattern from experiment 26 / TA.1** — both quantities are non-monotone in N.

**Implications for the "0.486" slope:**

The slope on log(threshold) = K_h − K_eff is also N-dependent:

| N | slope on log(f) (cleaner ε fit) |
|---|---|
| 2²⁰ | −0.91 (sign inverted) |
| 2²² | +0.10 |
| 2²³ | +0.34 |
| 2²⁴ | +0.45 |
| 2²⁵ | +0.44 |
| 2²⁷ | +0.35 |

The "0.486" reported at N=2²⁷ in TA.3 is an artifact of the mixed σ + 4-first-passage fit at that specific N. The true slope at N=2²⁷ via clean first-passage-only fit is **+0.35**, and it varies substantially across N. There is no single "1/2" asymptote in this data.

**Why does K_eff drop below K_h at intermediate N then rebound?** At very small N (2²⁰), the descent range covered by [f, n] is too narrow for the K_h heuristic to apply — most starts barely descend before crossing the threshold, giving anomalous local slopes. At intermediate N (2²³–2²⁵), the orbits sample the moderate-value regime where μ_β is below K_h (per exp 26), pulling K_eff down. At larger N (2²⁷), the descent range starts including more of the higher-value regime where μ_β is closer to K_h, lifting K_eff back up.

**Asymptote question remains open.** The 2²⁵ → 2²⁷ rebound (9.99 → 10.08) suggests K_eff is approaching K_h from below, but with oscillations consistent with TA.1's finding of μ_β oscillating around K_h with amplitude ≈ 0.01 at N ∈ [2²⁰, 2³²]. Pinning down the asymptotic behavior requires extending to N ≥ 2³² (matching exp 26's streaming-OLS range).

**Discriminator outcome:** the slope on log(threshold) is **not a structural constant**. It is a finite-N artifact bounded by Tao 2022's O((log N)^0.6) on subleading terms. The closed-form program for the slope is therefore equivalent to characterizing μ_β(N) → K_h convergence, which remains open (TA.1 follow-up).

### Bridge-equation reformulation (v3.1 framing)

The previous v3 framing treated the bridge equation as having four structural constants:
> s_mean(r; f(N)) ≈ α_det(r) + K_h · log(N/f(N)) + ε(σ) + (K_h − K_eff) · log(f(N))

with `K_h − K_eff = 0.486` listed as "empirically stable, mechanism open." Result 6 falsifies the stability premise — the value ranges from −0.91 at N=2²⁰ to +0.45 at N=2²⁴, with 0.486 itself being a TA.3 mixed-fit artifact at N=2²⁷.

**Correct form:**
> s_mean(r; f(N)) ≈ α_det(r) + K_h · log(N/f(N)) + ε(σ) + [K_h − μ_β(N)] · log(f(N))

with μ_β(N) the finite-N effective descent constant approaching K_h with oscillation. The "slope on log(threshold)" is a finite-N correction within Tao's O((log N)^0.6) bound — not a fixed structural slope.

**The four-constant decomposition collapses to three structural constants + one finite-N correction:**

| | Status |
|---|---|
| ⟨α_det⟩ = log(6)/log(4/3) | **Closed-form derived** (Result 1) |
| K_h = 3/log(4/3) | Tao's leading constant |
| ε(σ) | Decomposed into ε_S · log(6)/log(2) − ⟨α_det⟩ form; ε_S^(integer) ≈ log(4) within 0.5% pending 50M-orbit confirmation |
| [K_h − μ_β(N)] · log(f) | **Finite-N correction**, asymptotes to 0 as μ_β(N) → K_h, within Tao's bound |

**This collapses what looked like two open mechanisms (constants 3 and 4) into the same theoretical question.** The closed-form program for the slope is equivalent to the closed-form program for μ_β(N) → K_h convergence. Both are renewal-theoretic finite-N questions inside Tao's bound but with structure his leading term doesn't resolve.

**ε(σ) (constant 3) may also reduce to the same question.** ε(σ) is similarly a finite-N renewal residue; if ε_S^(integer) = log(4) is confirmed, ε(σ) becomes structurally pinned but its absolute value still inherits the same finite-N renewal corrections.

## Result 7: ε_S = log(4) — suggestive but NOT decisive at 50M precision

**Hypothesis (carried over from earlier work):** ε_S^(integer), the Syracuse-walk renewal residue, asymptotes exactly to log(4) = 1.3863. Earlier ≤2¹⁵M-orbit data showed ε_S ≈ log(4) within 0.5% at N=2³⁴; the test was whether 50M-orbit precision pins it within SE ≈ 0.003.

**Empirical test (experiment 38_eps_S_log4_test):** 50M random odd starts at each of N ∈ {2³², 2³⁴, 2³⁶}. Direct ε_S = ⟨σ_S⟩ − ⟨log N⟩/log(4/3); per-j Wald decomposition cross-check.

| N | ε_S | gap vs log(4) | z-score |
|---|---|---|---|
| 2³² | 1.3714 | −0.0149 (−1.07%) | **−4.39σ** |
| 2³⁴ | 1.3805 | −0.0058 (−0.42%) | −1.71σ |
| 2³⁶ | 1.3743 | −0.0120 (−0.86%) | **−3.53σ** |

SE ≈ 0.0034 per point. Verdict reported by the script: "Within 2-5σ of log(4). Suggestive but not decisive."

**Critical observation: ε_S is non-monotone in N.** Variation between N values (range 0.009) is **3× larger than the per-point SE**, so the spread is real oscillation, not sampling noise. The 2³⁴ point is closest to log(4); both 2³² and 2³⁶ pull away. Asymptotic fit `ε_S = ε_∞ + C/⟨log N⟩` gives **ε_∞ = 1.402** (= log(4) + 0.016), but the fit has 3 non-monotone points and isn't trustworthy as an asymptote estimate.

**Per-j structure IS clean and N-stable.** The j-stratified Wald W_j values are nearly identical across all 3 N values:

| j | P(j) | W_j @ 2³² | W_j @ 2³⁴ | W_j @ 2³⁶ |
|---|---|---|---|---|
| 2 | 0.938 | +7.154 | +7.166 | +7.161 |
| 4 | 0.024 | −4.757 | −4.738 | −4.764 |
| 5 | 0.038 | +4.602 | +4.585 | +4.563 |
| 8 | 0.0005 | +2.172 | +2.091 | +2.396 |

The per-j decomposition is structurally invariant; the noise lives in the **j-aggregation step**, not in any individual j-class.

**Unifying observation across Results 6 and 7:** ε_S oscillates with N (Δ ≈ 0.009 across 2³²–2³⁶), and so do K_eff (Δ ≈ 1.35 across 2²⁰–2²⁷, see Result 6) and μ_β (Δ ≈ 0.06 across 2²⁰–2³², from exp 26). All three are the **same finite-N renewal-residue phenomenon** measured through different observables. The structurally-invariant pieces (per-j W_j; per-residue α_det) are clean; the global aggregations all carry the same finite-N oscillation that hasn't been characterized analytically.

**Verdict on ε_S = log(4):** Not confirmed. The empirical value is within ~1% of log(4) across the tested range, but with non-monotone oscillation that's bigger than sampling noise and would need N ≥ 2³⁸–2⁴⁰ to discriminate "asymptotes to exactly log(4)" vs "asymptotes near log(4) (~1.40)." The clean theoretical claim "ε_S = log(4) closed form" is **not supported by 50M precision at N=2³⁶**.

The "three structural constants + one finite-N correction" picture needs softening. ε_S behaves the same way as K_eff and μ_β: structurally decomposable per-j, but the global value carries a finite-N oscillation that doesn't pin to a single closed form at currently-tractable N.
