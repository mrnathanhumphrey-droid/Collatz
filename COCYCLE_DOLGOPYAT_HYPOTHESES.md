# Algom–Rodriguez Hertz–Wang 2024 — Hypothesis structure (verbatim)

Source: arXiv:2306.01275v2 (1 Jul 2024). Extracted via pypdf, all 53 pages, file at C:/tmp/arhw_full.txt. Quotations preserve OCR artifacts (split hyphens, ﬃ/ﬀ ligatures) verbatim except where noted.

## (a) Theorem 1.1 — main result (p. 2, verbatim)

> **Theorem 1.1.** Let Φ be a uniformly contracting C^r(R) IFS where r ≥ 2. If Φ is not conjugate to a linear IFS then every non-atomic self-conformal measure ν admits some α = α(ν) > 0 such that
>
>     |F_q(gν)| = O(1 / |q|^α).

Followed by (p. 2): "Moreover, our argument yields easily veriﬁable conditions when Theorem 1.1 may be applied (without directly checking whether the IFS is conjugate to linear); As we discuss later, it suﬃces for a C²(R) IFS to satisfy conditions (9) and (10) below for the conclusion of Theorem 1.1 to hold true."

## (b) "Uniformly contracting C^r IFS" — verbatim definition (pp. 1–2)

> "let Φ = {f_1,...,f_n} be a ﬁnite set of strict contractions of a compact interval I ⊆ R (an IFS - Iterated Function System), such that every f_i is diﬀerentiable. We say that Φ is C^α smooth if every f_i is at least C^α smooth for some α ≥ 1."
>
> "We call Φ uniformly contracting if
>
>     0 < inf{|f'(x)| : f ∈ Φ, x ∈ I} ≤ sup{|f'(x)| : f ∈ Φ, x ∈ I} < 1."
>
> "We always assume that there exist i, j such that the ﬁxed point of f_i does not equal the ﬁxed point of f_j. This ensures that K is inﬁnite."

Self-conformal measure (p. 2):

> "let P = p^N be the corresponding Bernoulli measure on A^N. We call the measure ν = ν_p = πP on K the self conformal measure corresponding to p... Equivalently, ν_p is the unique Borel probability measure on K such that
>
>     ν = Σ_i p_i · f_iν, where f_iν is the push-forward of ν via f_i.
>
> When all the maps in Φ are aﬃne we call Φ a self-similar IFS and ν a self-similar measure."

## (c) Non-linearity hypothesis — both versions, verbatim (p. 2)

Linear IFS (C² case, p. 2):

> "we say that a C²(R) IFS Ψ is linear if g''(x) = 0 for every x ∈ K_Ψ and g ∈ Ψ. ... It is clear that if Ψ is C^ω(R) and linear then it must be self-similar."

C² conjugation (p. 2):

> "We say that a C^r IFS Φ is conjugate to an IFS Ψ if there is a C^r diﬀeomorphism h such that Φ = {h ∘ g ∘ h^{−1}}_{g∈Ψ}."

Hypothesis form used in Theorem 1.1: **"Φ is not conjugate to a linear IFS."**

C^ω case (Corollary 1.2, p. 3, verbatim):

> **Corollary 1.2.** Let Φ be a C^ω(R) IFS. If Φ contains a non-aﬃne map then every non-atomic self-conformal measure ν admits some α = α(ν) > 0 such that
>
>     |F_q(ν)| = O(1 / |q|^α).

Mechanism (Claim 6.1, p. 48, verbatim):

> **Claim 6.1.** Let Φ be a C^ω([0, 1]) IFS. Then there is a dichotomy:
> 1. Φ is not C² conjugate to linear, or
> 2. Φ is conjugate to a linear C^ω(R) IFS via an analytic map g, that is a diﬀeomorphism on [0, 1]. In particular, Φ is C^ω conjugate to a self-similar IFS.

In the analytic category there is no third option: an analytic non-affine map either makes the IFS non-conjugate-to-linear (Thm 1.1 applies) or makes it analytically conjugate to genuinely self-similar (a separate Algom et al. [2] theorem applies). **Affine = self-similar** in C^ω, and the framework EXCLUDES purely self-similar IFSs unless an analytic non-affine conjugacy exists.

## (d) UNI condition — verbatim (Claim 2.2, p. 6 + Theorem 2.4 part 5, p. 13)

Foundational UNI (Claim 2.2, p. 6, verbatim):

> **Claim 2.2.** There exist some c, m', N_0 > 0 such that for all n > N_0 there exist ξ, ζ ∈ A^n such that for every x ∈ [0, 1],
>
>     c < |d/dx (log f'_ξ − log f'_ζ)(x)| ≤ m'.

Origin (Claim 2.2 proof, p. 7, verbatim):

> "By [3, proof of Claim 2.13], if for all σ-periodic ξ, ζ ∈ A^N and x ∈ K we have
>
>     lim_n d/dx log f'_{ξ|n}(x) = lim_n d/dx log f'_{ζ|n}(x),    (6)
>
> then Φ is C² conjugate to a linear IFS. Thus, since Φ is not conjugate to linear, there exist some c' > 0, x_0 ∈ K and σ-periodic ξ, ζ ∈ A^N such that for inﬁnitely many n, [the cocycle-derivative gap is bounded below]."

This is THE load-bearing equivalence: **non-conjugate-to-linear ⟺ UNI**. The non-linearity hypothesis IS the cocycle UNI hypothesis. Linear IFSs (and IFSs conjugate to them) violate UNI by definition; the derivative cocycle log f'_I collapses to a single coboundary class.

Strengthened UNI in the model (Theorem 2.4 part (5), p. 13, verbatim):

> **5. (UNI in all parts)** There exist m', m > 0 and N_0 ≥ 0 such that for all N ≥ N_0, for every ω ∈ Ω there exist α_1^N, α_2^N ∈ X_N^{(ω)} such that
>
>     m ≤ |d/dx (log f'_{α_1^N} − log f'_{α_2^N})(x)| ≤ m', for all x ∈ [0, 1].

## (e) Derivative cocycle + transfer operator + spectral gap (verbatim)

Derivative cocycle (eq. 11, p. 10, verbatim):

> "Let G to be the free semigroup generated by the family {f_a : 1 ≤ a ≤ n}, which acts on [0, 1] by composing the corresponding f_a's. We deﬁne the derivative cocycle c : G × [0, 1] → R via
>
>     c(I, x) = −log|f'_I(x)|.    (11)"

Transfer operator (Definition 2.3, p. 10, verbatim):

> **Deﬁnition 2.3.** For every s ∈ C such that |ℜ(s)| is small enough, let P_s : C¹([0, 1]) → C¹([0, 1]) denote the transfer operator deﬁned by, for g ∈ C¹ and x ∈ [0, 1],
>
>     P_s(g)(x) = ∫ e^{2π · s · c(a,x)} g ∘ f_a(x) dp(a).

Spectral gap (Theorem 2.8, p. 17, verbatim):

> **Theorem 2.8.** Let Φ be a C²([0, 1]) IFS satisfying properties (9) and (10), and let ν = ν_p be a self-conformal measure. Then there exist C, γ, ε, R > 0 and some 0 < α < 1 such that for all |b| > R, a ∈ R with |a| < ε, and n ∈ N
>
>     ||P_{a+ib}^n||_{C¹} ≤ C · |b|^{1+γ} · α^n.    (21)

Polynomial Fourier decay conclusion form (Theorem 1.1, restated):

> |F_q(gν)| = O(1 / |q|^α),    α = α(ν) > 0.

The exponent α depends on the spectral-gap parameters (ε, α, γ) which depend on the IFS via the UNI constants m, m' and the contraction parameters ρ, ρ_min — but the paper does NOT give an explicit polynomial-in-A constant; α(ν) is implicit through the cocycle data.

## (f) "No Markov-partition cylinder cover required" — where it lives in the proof (p. 4, verbatim)

> "There are, among others, three critical properties of ν and Φ that are used in Naud's version [39] of Dolgopyat's method, which is the one we ultimately rely on here: That the union (1) corresponds to a Markov partition (i.e. for i ≠ j, f_i([0, 1]) and f_j([0, 1]) may intersect only at their endpoints), that the measure ν satisﬁes the Federer property (see e.g. Theorem 2.4 Part (6)), and that Φ satisﬁes the uniform non-integrability condition (UNI in short - see Claim 2.2). In our setting, since we assume no separation conditions (in particular, the cylinder covering is not a Markov partition), we cannot assume ν has the Federer property. As for (UNI), in our previous work [3, proof of Claim 2.13] we showed that if Φ is not conjugate to linear then (UNI) does hold true (regardless of any separation assumptions). In fact, our non-linearity assumption is only used to obtain the (UNI) condition.
>
> One of the main innovations of this paper is the introduction a cocycle version of Dolgopyat's method, that we use get around these issues: First, we express ν as an integral over a certain family of random measures, and express the transfer operator as a corresponding convex combination of smaller 'pieces' of itself. ... In our variant, that is closest to the construction in [1], these random measures typically satisfy a certain dynamical self-conformality relation with strong separation, and satisfy the Federer property. Critically, we are able to preserve the (UNI) condition into all the diﬀerent pieces of the transfer operator corresponding to this decomposition."

The mechanism that replaces a Markov partition is the **random-model disintegration** (Theorem 2.4): ν is written as ∫ μ_ω dQ(ω) over a finite IFS-of-IFSs index set, each μ_ω lives on a sub-IFS with **strong separation + Federer + UNI**, and the transfer operator decomposes accordingly (eq. 17). The "induced IFS of generation N" with Claim 2.1's f_1, f_2, f_3, f_4 supplies the disjointness and bounded-distortion needed to build the model.

**Critical: this replaces Markov partition with strong separation in a smaller sub-IFS — but it does NOT replace the underlying smooth-IFS structure or the cocycle's continuous-derivative cocycle property.** C^r(R) with r ≥ 2 and uniform contraction in (0,1) are non-negotiable.

## What's load-bearing for Syracuse

Every theorem and definition in this paper is stated for **strict contractions f_i of a compact interval I ⊆ R, every f_i differentiable, satisfying 0 < inf|f'| ≤ sup|f'| < 1**, with f''_i existing on K_Φ (C² minimum) and the cocycle c(I,x) = −log|f'_I(x)| a smooth-in-x quantity. Non-linearity is non-vanishing of f''(x) on K_Φ for at least one f ∈ Φ (or equivalently, non-equality of the cocycle-derivative limits along σ-periodic codings).
