# POLYMATH8 CHAIN — Chronological Map

**Purpose.** Track the Polymath8 chain of Tao blog posts + arXiv papers to determine whether any variant of the Type I/II/III framework treats (a) rough inputs, (b) prime-power moduli, (c) abelian-cardinality-side savings.

**Scope rule.** Only posts/papers in the Polymath8a / Polymath8b chain proper (descendants like Maynard's standalone work or post-2014 PiAP literature that uses descended methods are NOT in scope here).

## Generalize / Specialize / Restate classification (chain proper)

- **Phase 1, post 2 (Type I/II)** — GENERALIZES Zhang (replaces y-smooth with y-densely-divisible square-free; introduces general coefficient sequences with Siegel-Walfisz alternative to smoothness).
- **Phase 1, post 3 (Type III)** — RESTATES + completes the third Zhang estimate.
- **Phase 1, post 4 (DDM)** — GENERALIZES modulus class (singly densely-divisible).
- **Phase 1, post 7 (DDDM)** — GENERALIZES modulus class (k-tuply densely-divisible).
- **Phase 1, post 8 (Improved Type I)** — RESTATES + tightens.
- **Phase 3, paper A (1402.0811)** — DEFINITIVE polish of all above.
- **Phase 4 (all 8b posts)** — SPECIALIZE / consume — they hold 8a's estimates fixed and optimize the sieve side.
- **Phase 5, paper B (1407.4897)** — SPECIALIZES / consumes A as black box.
