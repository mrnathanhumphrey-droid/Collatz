## 1. Setup: SL_2(ℝ) random walks and Furstenberg measures

A **Furstenberg measure** of an SL_2(ℝ) random walk is the unique stationary distribution ν on
the projective line P^1(ℝ) for the action of a probability measure μ on SL_2(ℝ). That is, ν is
the unique Borel probability measure on P^1(ℝ) satisfying

    ν = ∫_{SL_2(ℝ)} g_* ν  dμ(g)        (stationarity)

where g_* ν is the pushforward of ν under the projective action of g ∈ SL_2(ℝ) on P^1(ℝ).
Existence and uniqueness of ν require Furstenberg's classical hypotheses:

- **(F1) Non-elementary support.** The subgroup G_μ generated by supp(μ) is non-elementary in
  SL_2(ℝ): it is non-compact and does not fix a point or pair of points in P^1(ℝ). Equivalently,
  G_μ is **proximal** (contains an element with two distinct real eigenvalues of different
  modulus) and **strongly irreducible** (no finite union of proper subspaces of ℝ² is G_μ-
  invariant).

- **(F2) Finite first moment.** ∫ log ‖g‖ dμ(g) < ∞ (this is the Furstenberg-Kifer-Hennion
  moment condition).

Under (F1)+(F2), the **top Lyapunov exponent** χ := lim_{n→∞} (1/n) ∫ log ‖g_n ⋯ g_1‖ dμ^{⊗n} is
strictly positive (Furstenberg's theorem); ν exists, is unique, and is non-atomic.

These are the BASELINE hypotheses for **every** result we examine below.

## 2. Dinh–Kaufmann–Wu 2021 (arxiv:2108.06006) — Rajchman property

**Theorem [paraphrase, DKW Theorem A].** Let μ be a Borel probability measure on SL_2(ℝ) such
that
  (i) the closed subgroup G_μ generated by supp(μ) is non-elementary, and
  (ii) ∫ ‖g‖^s dμ(g) < ∞ for some s > 0 (finite **exponential** moment for some exponent,
       i.e., ∫ log ‖g‖ dμ < ∞ suffices in the weakest form; many DKW results require ∫ ‖g‖^s < ∞).

Then the Furstenberg measure ν on P^1(ℝ) is **Rajchman**, i.e.,

    ν̂(k) → 0 as |k| → ∞.

**Hypothesis catalogue for DKW Rajchman:**
| Hypothesis | Precise condition |
|---|---|
| H_DKW_NONELEM | G_μ non-compact, proximal, strongly irreducible |
| H_DKW_MOMENT | ∫ log ‖g‖ dμ < ∞ (mild); some strengthenings require finite exp-moment |

DKW Rajchman is **qualitative**: it gives `|ν̂(k)| → 0` but **no rate**. For polynomial decay,
strengthening is needed (see §4).

## 3. Hochman–Solomyak 2017 (arxiv:1610.02641) — exact dimension, P^1 setting

**Theorem [paraphrase, HS Theorem 1.1].** Let μ be a finitely-supported probability measure on
SL_2(ℝ) such that
  (i) G_μ is non-elementary (proximal + strongly irreducible),
  (ii) all entries of all matrices in supp(μ) are **algebraic numbers**.

Let χ_1 > χ_2 = −χ_1 be the Lyapunov exponents of μ. Let h_RW(μ) denote the random-walk entropy

    h_RW(μ) := lim_{n→∞} (1/n) H(μ^{*n})

where μ^{*n} is the n-fold convolution and H(·) is Shannon entropy, with the convention that for
infinitely-supported measures one uses the Furstenberg entropy / random-walk entropy
generalization. Then the Furstenberg measure ν has **exact pointwise dimension**

    dim ν = min{1, h_RW(μ) / (2χ_1)}

unless there is an "exceptional" relation between the entries (an explicit Diophantine condition
ruling out resonances).

**Hypothesis catalogue for HS dimension formula:**
| Hypothesis | Precise condition |
|---|---|
| H_HS_NONELEM | G_μ proximal + strongly irreducible (same as DKW) |
| H_HS_FINITE_SUPP | μ is finitely supported (essential — HS's "exponential separation" lemma |
|                  | requires finiteness) |
| H_HS_ALGEBRAIC | All entries of all matrices g ∈ supp(μ) lie in a fixed algebraic number |
|                | field K ⊂ ℝ. The structure required is more than "individual entries algebraic":|
|                | the **action on K^2 (or its Galois conjugates)** must respect the algebraic |
|                | structure (so that the Galois-theoretic argument bounding `Δ_n :=` minimum |
|                | separation of n-fold compositions goes through). |
| H_HS_NO_EXCEPT | No Diophantine "exceptional" relation; for generic algebraic data this holds. |

**Important: "algebraic entries" alone is NOT enough.** HS requires the matrices in supp(μ) to
**live in SL_2(K) for an algebraic number field K**. The matrix g ∈ SL_2(K) is then acted upon
by Gal(K/ℚ), producing conjugate random walks whose Lyapunov exponents bound Δ_n from below.
Rational entries (K = ℚ) work trivially; but the matrices must still be in **SL_2** (det = 1) so
that the Lyapunov decomposition is well-defined.

## 4. Frostman-dimension update (arxiv:2601.14061) — quantitative bound

**Theorem [paraphrase, Frostman 2026].** Under the same hypotheses as Hochman-Solomyak
(H_HS_NONELEM + H_HS_FINITE_SUPP + H_HS_ALGEBRAIC + H_HS_NO_EXCEPT), there exist constants
C, α > 0 (effective in the data of μ) such that for every interval I ⊂ ℝ of length |I|,

    ν(I) ≤ C |I|^α

where α = min{1, h_RW(μ) / (2χ_1)} − ε for any ε > 0 (in the weak form) or with explicit
ε(μ) for an effective form.

This is the **Frostman-regular** strengthening of HS's pointwise-dimension result. Frostman
regularity at exponent α implies **polynomial Fourier decay**

    |ν̂(k)| ≪ |k|^{−α/2}

via the standard Mattila-type "Frostman → Fourier" inequality (the energy integral / Salem-Stein
lemma):  Frostman exponent α  ⟹  Hausdorff dimension ≥ α, and for measures supported on suitable
sets, Fourier decay at half the Frostman exponent.

**Crucial:** the Frostman → Fourier decay direction is not automatic. It needs that ν is a
measure on ℝ (or P^1 ≅ ℝ ∪ {∞}, which we treat as ℝ via stereographic projection at a base
point). Frostman regularity gives Fourier decay for the **non-atomic part** of ν.

## 5. Polynomial decay strengthening (Li 2020, DKW remark)

DKW remarks (this is the well-known Li 2020 / Bourgain-Furman-Lindenstrauss-Mozes lineage) that
the qualitative Rajchman result strengthens to **polynomial Fourier decay**

    |ν̂(k)| ≪ |k|^{−β}        for some β = β(μ) > 0

under the additional hypothesis:

- **(P) Diophantine non-degeneracy.** G_μ is **Zariski-dense** in SL_2(ℝ), or in slightly weaker
  variants, G_μ is **not contained in a compact-mod-center subgroup of SL_2(ℝ)**.

In other words: non-elementary alone gives Rajchman; Zariski-dense (or non-contained-in-compact-
mod-center) gives polynomial decay. The exponent β is positive but typically not effective in
this formulation; effective β requires additional structure (e.g., HS algebraic + finite support
+ explicit gap from the closest proper subgroup).

## 6. He–de Saxcé 2022 — torus random walks (parallel result)

For comparison, He–de Saxcé treat random walks on the d-torus 𝕋^d generated by a probability
measure μ on SL_d(ℤ). The hypotheses:

  (HdS-i) μ has finite support in SL_d(ℤ),
  (HdS-ii) the closed subgroup G_μ ⊂ SL_d(ℝ) acts irreducibly on ℝ^d and is non-elementary,
  (HdS-iii) the action on 𝕋^d has no finite invariant subset.

The conclusion is **exponential equidistribution of μ^{*n}-orbits on 𝕋^d** with explicit rate:
for f ∈ C^∞(𝕋^d) and x ∈ 𝕋^d,

    | ∫ f d(μ^{*n} * δ_x) − ∫ f dλ | ≤ C ‖f‖_{Sobolev} e^{−cn}

with c > 0 explicit in the data of μ.

**This is not the same setting as Furstenberg on P^1**: HdS works on a quotient 𝕋^d = ℝ^d/ℤ^d
of ℝ^d, not on the projective line of ℝ^2. But the hypothesis "non-elementary, irreducible,
finite support, integer entries" is structurally analogous, and the conclusion gives effective
mixing rates. HdS is the candidate framework if Syracuse dynamics maps to a torus random walk
rather than a Furstenberg-measure setup.

## 7. The four "structural compatibility" gates a candidate must pass

To apply the Furstenberg framework (any of DKW Rajchman / HS dimension / Frostman-dimension /
Li polynomial decay) to a candidate SL_2(ℝ) embedding, the embedding must satisfy ALL of:

| Gate | Precise condition | Comment |
|---|---|---|
| G1: SL_2 membership | The candidate matrices g_i satisfy det(g_i) = 1 (or after normalization). | Trivially mechanical; check determinants. |
| G2: Non-elementary | G_μ = ⟨supp(μ)⟩ is non-compact, proximal (contains hyperbolic element), strongly irreducible (no finite union of lines in ℝ² invariant). | Requires checking the **subgroup** generated, not individual matrices. A single hyperbolic element is enough for proximality; strong irreducibility needs ≥ 2 generators with no common invariant set in P^1. |
| G3: Moment condition | ∫ log ‖g‖ dμ(g) < ∞ (minimum); ∫ ‖g‖^s dμ for some s > 0 (strengthen). | For finite-support μ, automatic. |
| G4 (HS only): Algebraic structure | Entries of g_i in algebraic number field K; matrices in SL_2(K); no exceptional Diophantine relation. | Rational entries are algebraic trivially; the additional structure is "lives in SL_2(K) not just GL_2(K)". |

For **polynomial decay**, add:

| Gate | Precise condition | Comment |
|---|---|---|
| G5: Zariski-dense (Li 2020 strengthening) | G_μ is Zariski-dense in SL_2(ℝ); equivalently, not contained in a 1-dim algebraic subgroup. | Generic for non-elementary random walks; requires explicit check for arithmetic-cocycle data. |

## 8. Transfer of polynomial decay through projection — additional gate

If a candidate SL_2 embedding satisfies G1-G5 and yields polynomial decay |ν̂(k)| ≪ |k|^{−β}
for the Furstenberg measure ν on P^1, the **transfer to μ_n** (the Syracuse stationary measure
on 𝕋 ≅ ℤ_3 or ℝ/3^n ℤ) requires:

| Gate | Precise condition | Comment |
|---|---|---|
| T1: Projection / pushforward identifiable | There exists a Borel map π : P^1 → 𝕋 (or to ℤ_3) such that π_* ν is comparable to μ_n in a way that preserves Fourier decay. | Most projections destroy Fourier decay; the projection needs to be **Lipschitz with positive Jacobian** for elementary preservation, or **algebraic + non-flat** for the Algom-Baker-Sahlsten / Mattila pushforward machinery. |
| T2: Polynomial-in-A normalization | The decay rate β translates to a polynomial-in-A bound `|μ̂_n(ξ)| ≪ A^{−γ} f(ξ)` of the form Tao Prop 1.17 wants. | This is the "polynomial-in-A C_A" question. If β depends on A polynomially through the projection, the unblocker delivers; if β is A-independent or grows wrongly, the result doesn't unblock. |
