# FAURE candidates I, J — supporting frameworks (Liverani / Gouëzel-Liverani / Pollicott-Sharp / Parry-Pollicott)

## I. Liverani 1995, Gouëzel-Liverani 2006 — anisotropic Banach space framework

These are TECHNICAL SUPPORTING tools that the Faure-Tsujii program uses (anisotropic Banach spaces of distributions adapted to a hyperbolic map's stable-unstable splitting). They are NOT standalone closure theorems for Syracuse.

The Liverani / Gouëzel-Liverani machinery REQUIRES:
- A hyperbolic / partially-hyperbolic SMOOTH map on a smooth manifold
- A stable-unstable splitting (in some smooth or Hölder sense)
- Anisotropic Banach space construction tailored to that splitting

Syracuse: no smooth manifold, no splitting in the geometric sense. Liverani framework cannot be deployed.

## J. Pollicott-Sharp 2018, Parry-Pollicott 1990 — dynamical zeta function framework

Dynamical zeta functions ζ_dyn(s) = exp(Σ_{n≥1} (1/n) tr(L^n)) for transfer operator L of an Axiom A / Anosov / hyperbolic system, with meromorphic continuation and poles at Ruelle resonances.

REQUIRES: Axiom A / Anosov / smooth hyperbolic system on a smooth manifold.

Syracuse: not in this category. The "dynamical trace" of Tao's recursion operator is the Plancherel sum Σ |μ̂_n(ξ)|² = S_n at level n, which has different structural properties than Pollicott-Sharp's tr(L^n).

## Net

Both I and J are CATEGORICALLY INCOMPATIBLE with Syracuse's profinite-discrete object class. NO_FIT for the same fundamental reason: smooth-manifold hyperbolic dynamics is the input class.
