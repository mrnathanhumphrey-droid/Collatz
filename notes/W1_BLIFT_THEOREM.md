## 1. Verbatim hypotheses (HS 2014 §2.1)

Let `B` be a unital algebra and `A` a unital algebra containing `B` as a
subalgebra, with the unit of `B` equal to the unit of `A`. A subalgebra
`C` of `A` over `B` is a subalgebra of `A` such that `bc ∈ C` for all
`b ∈ B` and `c ∈ C`. For random variables `X_1, ..., X_r ∈ A`, let
`B⟨X_1, ..., X_r⟩_0` denote the subalgebra of `A` over `B` consisting of
finite sums of elements
`{b_1 X_{i_1} b_2 ⋯ X_{i_n} b_{n+1} : b_i ∈ B, n ≥ 1, i_1, ..., i_n ∈ {1, ..., r}}`.

A `B`-linear map `ϕ : A → B` with `ϕ(b) = b` for `b ∈ B` is called a
**conditional expectation**. The triple `(A, B, ϕ)` is called an
**algebraic / noncommutative probability space**.

## 2. Verbatim definitions (HS 2014 §2 + §3)

### Definition 2.1 (HS 2014, p. 2) — Operator-valued joint moments

For a random vector `X = (X_1, ..., X_r) ∈ A^r` and indices
`i_1, ..., i_n ∈ {1, ..., r}`, the **multilinear functional**
`μ_{i_1, ..., i_n}^X : B^n → B`
is defined by
> `μ_{i_1, ..., i_n}^X(b_1, ..., b_n) = ϕ(b_1 X_{i_1} b_2 ⋯ b_n X_{i_n})`.

### Definition 2.2 (HS 2014, p. 3) — Monotone independence over B
*(Skeide 2004)*

Let `Λ` be an index set with a linear order `<`. A family of subalgebras
`(A_λ)_{λ ∈ Λ}` of `A` **over `B`** is said to be **monotone independent
over `B`** if
> `ϕ(X_1 ⋯ X_n) = ϕ(X_1 ⋯ X_{i-1} ϕ(X_i) X_{i+1} ⋯ X_n)`

holds for any `X_i ∈ A_{λ_i}` whenever `i` satisfies `λ_{i-1} < λ_i` and
`λ_i > λ_{i+1}` (one of the inequalities is eliminated when `i = 1` or
`i = n`).

Independence for random vectors `X_λ = (X_{λ,1}, ..., X_{λ,k_λ})`,
`λ ∈ Λ`, is defined by considering the subalgebras
`A_λ := B⟨X_{λ,1}, ..., X_{λ,k_λ}⟩_0`.

### Definition 2.3 (HS 2014, p. 3) — Dot operation

Given monotone-iid copies `{X^{(j)}}_{j ≥ 1}` of `X ∈ A` in an extended
algebraic probability space `(Ã, B, ϕ̃)`, the **dot operation** is
`N.X := X^{(1)} + ⋯ + X^{(N)}` for `N ∈ N`.

### Definition 3.3 (HS 2014, p. 6) — n-th joint cumulant

The **n-th joint cumulant**
`K_n(X_1, ..., X_n) := K_n^X ∈ B`
is defined as **the coefficient of `N` in the polynomial
`ϕ((N.X_1)(N.X_2) ⋯ (N.X_n))`** (which is a polynomial in `N` of degree
`n` without constant term — established by Lemma 3.1).

For a non-crossing partition `π = (V_1, ..., V_k)` with interval block
`V = {k, ..., k+m}`, the partition cumulant `K_π` is defined recursively
by Speicher's interval-block contraction rule:
> `K_π(X_1, ..., X_n) = K_σ(X_1, ..., X_{k-1}, K_{m+1}(X_k, ..., X_{k+m})
> X_{k+m+1}, ..., X_n)`,
where `σ` is the non-crossing partition of `n\V` obtained by removing the
interval block `V`. For monotone partitions `π = (V_1, ..., V_k) ∈ M(n)`
(non-crossing partitions with a compatible linear order on blocks: inner
blocks come later in the linear order), `K_π` is defined in the same way,
ignoring the linear order in the recursive expansion.

## 3. The two verbatim theorems

### Theorem 3.4 (HS 2014, p. 7) — Operator-valued moment-cumulant formula

> *"The following moment-cumulant formula holds:*
> `ϕ(X_1 ⋯ X_n) = Σ_{π ∈ M(n)} (1/|π|!) K_π(X_1, ..., X_n).`"

### Proposition 3.5 (HS 2014, p. 7) — B-amalgamated additivity / extensivity

> *"For `X = (X_1, ..., X_n) ∈ A^n`,*
> `K_n^{N.X} = N K_n^X.`"

## 4. The Syracuse specialization (the lifted statement)

### Theorem (B-amalgamated monotone cumulant additivity, abelian-B, Syracuse)

Let `(A, E_B, B)` be the operator-valued probability space defined in
`C:/Collatz/AMALG_FREENESS_SETUP.md`:

- `A = W*({T_j, M_{b_{[1,k]}} : j, k ≥ 1}) ⊆ B(H ⊗ L²(Ω, μ_{Geom}))`
- `B = W*({M_{b_{[1,j]}} : j ≥ 1})` (abelian von Neumann algebra of
  multiplication-by-accumulator-history operators; commutativity established
  in SETUP.md §4)
- `E_B = ϕ : A → B` the conditional expectation onto B with respect to
  the natural normal faithful tracial state on A; `E_B` is B-bilinear
  and satisfies `E_B(b) = b` for all `b ∈ B` (standard, SETUP.md §5).

Let `X̃_j = Off_j - E_B(Off_j)` (marginal-centering reading, operative per
`AMALG_FREENESS_MOMENT_CALCULATION.md §8`) for `j ∈ {1, 2, 3, ...}` indexed
by the natural total order. Let `A_j := B⟨X̃_j⟩_0` denote the subalgebra
of `A` over `B` generated by `X̃_j` in the sense of HS 2014 §2.1.

**Hypothesis (H1).** The family `(A_j)_{j ≥ 1}` is monotone independent
over `B` in the sense of HS 2014 Definition 2.2 — i.e., for all
`X_1 ∈ A_{λ_1}, ..., X_n ∈ A_{λ_n}` and all `i` with
`λ_{i-1} < λ_i > λ_{i+1}`,
> `E_B(X_1 ⋯ X_n) = E_B(X_1 ⋯ X_{i-1} E_B(X_i) X_{i+1} ⋯ X_n)`.

**Conclusion.** Define the n-th joint cumulant
`κ_n^B(X̃_{j_1}, ..., X̃_{j_n}) ∈ B`
as the coefficient of N in the polynomial
`E_B((N.X̃_{j_1})(N.X̃_{j_2}) ⋯ (N.X̃_{j_n})) ∈ B`
(HS 2014 Definition 3.3, specialized to our setting with `ϕ = E_B`).
Then:

**(i) Moment-cumulant formula (HS 2014 Thm 3.4).** For all
`n ≥ 1` and all multi-indices `(j_1, ..., j_n)`,
> `E_B(X̃_{j_1} ⋯ X̃_{j_n}) = Σ_{π ∈ M(n)} (1/|π|!) κ_π^B(X̃_{j_1}, ..., X̃_{j_n})`,

where `M(n)` is the set of monotone partitions of `{1, ..., n}` (HS 2014
§3 / Hasebe monograph Defn 3.23) and `κ_π^B` is the partition cumulant
defined by Speicher's interval-block contraction rule applied to the
B-multilinear functionals `κ_n^B`.

**(ii) B-extensivity (HS 2014 Prop 3.5).** For monotone-iid copies of
the random vector `X = (X̃_{j_1}, ..., X̃_{j_n})`,
> `κ_n^{B, \ N.X} = N · κ_n^{B, X}.`

### Proof.

Both (i) and (ii) follow directly from HS 2014 Theorem 3.4 and Proposition
3.5, applied to `(A, B, ϕ) := (A, B, E_B)`. We verify the hypotheses of
HS 2014:

(H-a) `B` is a unital algebra (in fact, a unital von Neumann algebra; its
abelianness is irrelevant to HS 2014, which assumes no commutativity).
SETUP.md §4 establishes this.

(H-b) `A` is a unital algebra containing `B` as a subalgebra, with unit
of `B` equal to unit of `A`. SETUP.md §3-§4: both are von Neumann
algebras with the common identity `I_{H ⊗ L²(Ω)}`.

(H-c) `E_B : A → B` is B-linear and satisfies `E_B(b) = b` for all
`b ∈ B`. SETUP.md §5: standard property of conditional expectations
onto von Neumann subalgebras with respect to the natural trace; explicit
realization given there.

(H-d) The subalgebra `A_j = B⟨X̃_j⟩_0` is a subalgebra of `A` over `B`
in the sense of HS 2014 §2.1. Indeed: `X̃_j ∈ A`, and for any `b ∈ B`
and `c ∈ A_j`, we have `bc ∈ A_j` (B-bimodule closure is part of the
definition of `B⟨X̃_j⟩_0`).

(H-e) The family `(A_j)_{j ≥ 1}` is monotone independent over `B`
(hypothesis H1 above). This is the Syracuse-specific input that makes
the Hasebe-Saigo machinery apply. The hypothesis is supported by:
- the framework-identification finding of `OBSTRUCTION_MAP_TERMINAL.md`
  (monotone, not free; 11-arc obstruction map terminal);
- the numerical diagnostic at `monotone_diagnostic_n3.json` showing
  `|M_3_alt| / |M_2| ≈ 10⁶` separation under marginal-centering reading B
  (the operative reading per `AMALG_FREENESS_MOMENT_CALCULATION.md §8`);
- the Hasebe-monograph Defn 1.21 peak-rule factorization predicting
  `E_B(X̃_{j_1} X̃_{j_2} X̃_{j_1}) = E_B(X̃_{j_2}) · E_B(X̃_{j_1}²)`
  which matches the diagnostic value at n=3.

Under (H-a)-(H-e), HS 2014 §3 proves Definition 3.3 (cumulants are well-
defined as coefficients of N in a polynomial; Lemma 3.1 establishes
polynomiality), Theorem 3.4 (moment-cumulant formula), and Proposition
3.5 (B-extensivity). The proofs are independent of any commutativity
property of B — Lemma 3.1's induction (Step 1: map LP(n) → NC(n); Step 2:
polynomial summation) and Theorem 3.4's derivation (via [6, Prop 5.1,
Cor 5.2, Thm 5.3] arguments "easily extended to the operator-valued
setting" — HS 2014 p. 6 explicit) use only the B-bimodule structure of
the multilinear functionals and the recursive contraction by interval
blocks. ∎
