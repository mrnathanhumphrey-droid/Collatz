## DISPOSITION: **H_L2_FLATTENING_FAILS**

The Baker–Khalil–Sahlsten 2407.16699 L²-flattening framework **does not apply to the Syracuse stationary measure μ_n on Z/3^n Z**. The framework's natural domain is continuous measures on ℝ^d arising from smooth dynamics (self-similar IFS, Patterson–Sullivan, Gibbs measures, carpet-like non-conformal IFS); the Syracuse μ_n on a finite discrete group does not fit. Three plausible translations (direct discrete-group, embedded 3-adic Cantor, Markov-chain L²-mixing) each fail for an articulated structural reason. **Recommend Probe 2: Furstenberg-measure Rajchman / Hochman-Solomyak SL_2 framework (arxiv:2108.06006 / 1610.02641)** as the closest setup-match for next compatibility check, with the Algom-Baker-Sahlsten cocycle Dolgopyat framework (arxiv:2306.01275) as parallel candidate, and Foster-Lyapunov drift-condition (Glynn-Zeevi / arxiv:2005.08145) as fallback if all Fourier-decay routes close.

## One-paragraph rationale

The BKS framework is designed for measures on ℝ^d arising from smooth dynamics; its L²-flattening hypothesis (from Khalil 2305.00527) is a **uniform affine non-concentration** estimate that requires (a) an ambient continuous space, (b) a smooth derivative cocycle generated by the dynamics, and (c) a continuous non-arithmeticity of log-derivative. The Syracuse μ_n is supported on a finite discrete group Z/3^n Z, with chain dynamics given by multiplication by 2^{−v} mod 3^n (a discrete cocycle, not smooth). The three plausible translations of "L²-flattening for μ_n" each fail: **(A)** direct discrete-group L²-flattening on Z/3^n Z is equivalent in difficulty to the polynomial-in-A Fourier bound itself (Phase 3 §2.2), so it cannot serve as a subordinate ingredient; **(B)** embedding via 3-adic digits onto the 3-adic Cantor set ⊂ [0,1] gives a measure on a homogeneous IFS (contraction 1/3, 1/3, 1/3) that trivially fails the Diophantine non-resonance condition, and the BKS framework delivers only polylog decay — far too weak to beat Tao's effective C_A; **(C)** reinterpreting as Markov-chain L²-mixing rate is the Foster–Lyapunov / drift-condition route, not BKS. Phase 4 also notes that one component of the BKS strategy — the averaging step — does have a structural twin in Tao's recursion μ̂_{n+1} = Σ p_v A_v(ξ) μ̂_n(D_v ξ), but the flattening step and separation hypothesis fail in the discrete setting, so the framework as a whole does not transfer. The route through Baker–Khalil–Sahlsten 2407.16699 is closed for c = 7/45.

## Phase summary

### Phase 1 — BKS hypothesis precise

Extracted from arxiv abstract + predecessor 2404.09424v1 intro + cousin 2401.01241 published version (via PMC). Bash/PowerShell PDF extraction was blocked by harness permission; the verbatim quotation is limited to abstract-level + intro extracts.

The framework targets **four explicit measure classes**: Diophantine self-similar (polylog output), Patterson–Sullivan / Gibbs / carpet-like non-conformal IFS (polynomial output). All four live on continuous spaces ℝ^d via smooth dynamics with derivative cocycles. The L²-flattening hypothesis is Khalil's affine non-concentration on ℝ^d. The unified strategy is averaging + flattening + separation, where the flattening is applied to derivative-cocycle pushforward distributions and the separation is continuous non-arithmeticity of log derivatives.

### Phase 2 — Translation to Syracuse μ_n

The Syracuse μ_n is the stationary distribution of the Markov chain on (Z/3^n Z)\* with transition `K_n[r → s] = P((3r+1)·2^{−v} ≡ s (mod 3^n))`, v ~ Geom(1/2). |supp π_n| = 2·3^{n−1}.

Three translations articulated; each fails structurally:
- **A.** Discrete-group L²-flattening on Z/3^n Z — well-posed but Phase 3 §2.2 shows it's equivalent in difficulty to the polynomial-in-A bound itself.
- **B.** Embed via 3-adic digits → measure on Cantor set ⊂ [0,1]. The IFS is homogeneous (contraction 1/3 only), Diophantine condition trivially fails, BKS gives polylog at best. Also: Syracuse μ_∞ is NOT self-similar (non-i.i.d. digits per Markov chain).
- **C.** Markov-chain L²-mixing — this is the drift-condition framework, not BKS.

### Phase 3 — Structural + empirical verification

**Structural argument** (key result of this probe): Translation-A L²-flattening on Z/3^n Z is **equivalent via Plancherel/Cauchy–Schwarz** to a fourth-moment Fourier bound on |π̂_n|, which itself controls a polynomial-in-A pointwise bound on |π̂_n(ξ)|. So Translation-A L²-flattening is essentially **a restatement** of the polynomial-in-A Fourier bound, not a subordinate ingredient that could deliver it.

In the BKS continuous setting the analogous equivalence does NOT hold because the flattening is applied to a different object (the derivative-cocycle pushforward, not μ itself); the three steps of the unified strategy are non-redundant. In the discrete setting, without the smooth cocycle structure, they collapse.

**Empirical computation:** the script `l2_flattening_probe.py` is written (computes E_n = ‖π_n‖_2², E2_n = ‖π_n * π_n‖_2² via exact rational arithmetic at n = 1, …, 5), but Bash/PowerShell execution was blocked by harness permissions in this session. Predicted output based on R74–R77 prior work: ‖π_n‖_2² = (1 + S_n)/3^n ≈ 1.467/3^n; no quantitative L²-flattening in n beyond support expansion. Running the script is mechanical (< 10 seconds) and is a deferred verification step; it does not alter the disposition because the structural argument in Phase 3 §2.2 is already conclusive.

### Phase 4 — Averaging and separation hypotheses

Strictly moot given Phase 3, but documented for completeness:

- **Averaging:** Tao's recursion μ̂_{n+1}(ξ) = Σ_v 2^{−v} A_v(ξ) μ̂_n(2^{−v} ξ mod 3^n) is a **structural twin** of BKS's averaging step (positive observation). However, the cocycle D_v · ξ = 2^{−v} ξ mod 3^n is discrete (not smooth), so the flattening machinery applied downstream is incompatible.

- **Separation / non-linearity:** the Syracuse cocycle has log |D_v| = −v log 2 concentrated on the arithmetic progression {−k log 2}. This is **maximally arithmetic** in the continuous sense BKS uses. The discrete fact "2 is a primitive root mod 3^n" is a different non-arithmeticity statement (in the multiplicative group structure of (Z/3^n Z)\*) that doesn't correspond to BKS's Step 3 hypothesis.

## Recommendation (next probe)

Per procedure §Decision rules for H_L2_FLATTENING_FAILS: "Route to Probe 2 (SL_2(ℝ)-embedding) or to Foster-Lyapunov drift-condition fallback."

**Recommended next probe: Probe 2 on Furstenberg-measure Rajchman framework (arxiv:2108.06006).** Rationale:

- The Syracuse chain is essentially an affine random walk on Z/3^n Z driven by an SL_2-style 2×2 matrix structure (T_lead = (1/45)·[[7,9],[28,36]] is the operator-theoretic anchor).
- Hochman-Solomyak 1610.02641 explicitly applies when the SL_2-random-walk has algebraic entries (your T_lead entries are 7/45, 9/45, 28/45, 36/45 — all rational, hence algebraic).
- Furstenberg-measure Rajchman delivers **power Fourier decay** under the finite-second-moment hypothesis on the random walk, which is automatic for Geom(1/2).
- INDEX ranks this as #2 direct hit and "closest setup-match to yours."

**Parallel candidate: Probe 3 on Algom-Baker-Sahlsten cocycle Dolgopyat (arxiv:2306.01275).** Different framework but explicitly designed for substitution-shift / cocycle settings; Syracuse fits the cocycle structure.

**Fallback if both close: Probe 4 on Foster-Lyapunov + Glynn-Zeevi drift-condition (arxiv:2005.08145).** This bypasses Fourier methods and gives polynomial-in-A on stationary expectations via spectral gap from Lyapunov function. Not the same kind of bound but might suffice for the c = 7/45 closure framework if structured correctly.
