# FAURE candidate F — Dyatlov-Guillarmou 2014 "Pollicott-Ruelle resonances for open systems"

**Source:** Dyatlov-Guillarmou 2014, extracted via pypdf cleanly.

## Verbatim hypotheses (Theorem 1)

> "Under the assumptions (A1)–(A5), the family R(λ) defined in (1.11)... [meromorphic continuation] ...has resonances at poles."

> "(A1) X is a smooth vector field on a smooth manifold M.
> (A2)–(A5) Hyperbolic trapped-set conditions: incoming/outgoing tails Γ± ⊂ U and trapped set K, with hyperbolicity on K (uniform contraction/expansion of E_u, E_s on K)."

> "**Theorem 2.** For each λ_0 ∈ C, we have the expansion of R(λ) near λ_0 as a finite-rank principal part + holomorphic remainder."

> "**Theorem 3.** Assume that the stable/unstable foliations E_u, E_s are orientable. Then [the dynamical zeta function has meromorphic continuation to C with zeros/poles at resonances]."

## Identification

(i) THE MAP: smooth vector field X on smooth manifold M, with HYPERBOLIC TRAPPED SET (escape behavior in non-trapped region).
(ii) FUNCTION SPACE: anisotropic Sobolev spaces adapted to the trapped set / non-orientable extensions.
(iii) EXPANSION: hyperbolicity on the trapped set K (uniform exp contraction/expansion on E_u, E_s).
(iv) CONCLUSION: meromorphic resolvent with discrete resonances (Pollicott-Ruelle).

## Match to Syracuse

Open-system extension. Syracuse arguably has "open" behavior: trajectories on the natural numbers either reach 1 (escape into the trivial cycle) or continue. BUT this open structure is in the dynamical NUMBER-THEORETIC sense, not in the smooth-manifold sense the theorem requires. The trapped set K must be a SMOOTH submanifold of T*M with uniform hyperbolicity — Syracuse has no smooth manifold structure. NO_FIT by category.
