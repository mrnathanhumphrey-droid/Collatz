## Faure 2009 Theorem 2 proof skeleton (verbatim, pdfminer)

The structure of the proof we are porting (Faure 2009 §4, lines 1180-4325 of `C:/tmp/faure/Faure_2009_Semiclassical_Spectral_Gap_Partially_Expanding_pdfminer.txt`):

> **Theorem 2 (Spectral gap in the semiclassical limit).** if the map f is partially captive (definition given page 15) (and m small enough), then the spectral radius of the operator F̂_ν : H^m(S¹) → H^m(S¹) does not depend on m and satisfies in the semi-classical limit ν → ∞: r_s(F̂_ν) ≤ 1/√E_min + o(1) which is strictly smaller than 1 from (3).

**Proof structure (load-bearing steps):**

1. **Conjugation by anisotropic weight Â_m**: Q̂ := Â_m F̂_ν Â_m^{-1} : L²(S¹) → L²(S¹). Â_m is a PDO whose symbol A_m(x,ξ) is built from an *escape function* on T*S¹ (smooth manifold).

2. **B̂ := F̂_ν* Â_m² F̂_ν is a PDO** with symbol in S^m (Lemma 1 = Egorov):
   B(x,ξ) = Σ_{ε=0,…,k-1} (1/E'(x'_ε)) · A²_m(F_ε(x,ξ)) + R, R ∈ S^{m-1}.
   The Egorov theorem ("the main Theorem used in order to establish both the existence of a discrete spectrum of resonances and properties of them") explicitly invokes **smooth Fourier integral operator composition** under the smooth dynamics F.

3. **Principal symbol of P̂ := Q̂*Q̂ at time n** (eq 35):
   P^(n)(x,ξ) = Σ_{ε ∈ {0,…,k-1}^n} (1/E'_n(x)) · [A²_m(F^n_ε(x,ξ)) / A²_m(x,ξ)]
   bounded by case analysis (eqs 36-38) splitting trajectories into those that enter trapped set Z vs not.

4. **L²-continuity theorem for PDOs** gives ||P̂^(n)|| ≤ B + O_n(ℏ) where B = (k/E_min)^n · |C₂^m| + (n-N(n)-1)·|C₂^m|/E_min^n (eq 39).

5. **Polar decomposition** of Q̂^n + spectral theorem gives r_s(Q̂) ≤ ||Q̂^n||^{1/n} ≤ B^{1/2n} + ... → 1/√E_min as n→∞, ℏ→0.

The five load-bearing smoothness ingredients: T*S¹ cotangent bundle, escape function A_m, PDO calculus on S¹, Egorov composition, L²-PDO continuity. Step 5 (polar + spectral radius) is base-agnostic.

## Recipe Component 1 — REPLACE T² (smooth base) with Z_3* × neutral fiber

### Verbatim findings

**Cartwright-Kaimanovich-Woess 1994** (`adelic/Cartwright_Kaimanovich_Woess_1994_Random_Walks_Affine_Local_Fields.txt`, pp.30-37):

> "Let 𝔉 be a field with a discrete valuation v ... 𝒪 = {u ∈ 𝔉 : v(u) ≥ 0} valuation ring ... 𝔉 is called a (non-archimedean) local field, if (I) the cardinality q of the residual field 𝒪/𝔓 is finite ... and (II) 𝔉 is complete ... Assuming (II), (I) is equivalent to the local compactness of 𝔉. We choose a uniformizer p ∈ 𝔉 such that v(p) = 1. ... Then every u ∈ 𝔉^* can be uniquely written as u = Σ_{i=n}^∞ s_i p^i ... In the particular case when 𝔉 = Q_p ... is the standard representation of p-adic numbers."

The construction of tree T_𝔉 = Bruhat-Tits tree from balls U_k(u):
> "The vertex set of our tree is 𝒯 = {U_k(u) : u ∈ 𝔉, k ∈ Z} ... The father of a vertex x = U_k(u) is y = U_{k-1}(u). This defines the tree structure in T, and ℋ_k is the k-th horocycle. ... T is homogeneous of degree q+1."

Affine group action on tree:
> "AFF(𝔉) = {u ↦ au+b : a ∈ 𝔉*, b ∈ 𝔉} ≅ {(a b; 0 1) : a,b ∈ 𝔉, a ≠ 0}, the group generated by the canonical actions on the field 𝔉 of its additive and multiplicative groups. ... AFF(𝔉) realized as a closed subgroup of AFF(T) which acts transitively on T."

CKW's results on this object: CLT + LIL + Poisson boundary / Martin compactification for random products of affine matrices on 𝔉 = Q_p — **NOT a spectral-gap theorem for a transfer operator**, but the underlying space (tree T_{Q_p} + affine group action + ends ∂*T = Q_p) is structurally identical to what Syracuse needs.

**Anker-Schapira-Trojan 2013** (`adelic/Anker_Schapira_Trojan_2013_Heat_Kernel_Affine_Buildings.txt`, pp.2-3):

> "Bruhat-Tits buildings, or more generally affine buildings ... are discrete analogues of Riemannian symmetric spaces. ... We define the corresponding averaging operator acting on functions on V_P as Af(x) = Σ_{y ∈ V_P} p(x,y) f(y). Then the Gelfand-Fourier transform of A, denoted as Â, is a W_0-invariant exponential polynomial expressed as a combination of Macdonald spherical function P_ω."

The full asymptotic of the heat kernel p(n;x,y) on Bruhat-Tits buildings (Theorem A):
> "p(n; o, x_n) = n^{-r/2 - |Φ^{++}|} P_{ω_n}(0) ρ^n e^{-n φ(δ_n)} (K_0 + O(|δ_n|) + O(n^{-1}))."

## Recipe Component 2 — REPLACE C^∞ with continuous-on-profinite + level filtration

### Verbatim findings

**Kozyrev 2007** (`crystal/kozyrev.txt`, p.2-6): function space on Q_p with explicit p-adic Fourier transform basis:

> "F[f](ξ) = ∫_{Q_p} χ(ξx) f(x) dμ(x) ... where χ(ξx) = exp(2πi{ξx}) is the character of the field of p-adic numbers ... Vladimirov operator D^α_x = F^{-1} ∘ |ξ|^α_p ∘ F"

Orthonormal basis (Theorem 2):
> "ψ_{γjn}(x) = p^{-γ/2} χ(p^{γ-1} j x) Ω(|p^γ x - n|_p), γ ∈ Z, n ∈ Q_p/Z_p, j = 1,…,p-1 ... is an orthonormal basis in L²(Q_p) of eigenvectors of the operator D^α: D^α ψ_{γjn} = p^{α(1-γ)} ψ_{γjn}."

This is the **p-adic Sobolev** machinery: the level γ provides the natural filtration analogous to the smooth Sobolev order m.

[NON_VERBATIM, per user's brief metadata]: Albeverio-Khrennikov-Shelkovich 2005 — p-adic Lizorkin spaces with hyperbolic invariance and PDO; Khrennikov-Shelkovich 2006 — multi-dimensional p-adic wavelets generalizing Kozyrev's basis to (Q_p)^n.

[NON_VERBATIM, standard reference]: Bruhat-Schwartz space S(Q_p) = compactly supported locally constant complex-valued functions on Q_p. Pontryagin dual: 𝔻(Q_p)' (distributions), tempered distributions analog.

## Recipe Component 4 — REPLACE Egorov with profinite-Fourier composition

### Verbatim findings

**Faure 2009 Lemma 1** (Egorov, `faure/Faure_2009_…_pdfminer.txt` lines 2581-2620, verbatim):

> "Lemma 1. (Egorov theorem). B̂ := F̂_ν* Â²_m F̂_ν is a pseudo-differential operator with symbol in S^m given by: B(x,ξ) = Σ_{ε=0,…,k-1} (1/E'(x'_ε)) A²_m(F_ε(x,ξ)) + R with R ∈ S^{m-1} has a subleading order."

The proof uses smooth canonical map F⁻¹∘F = Id and FIO composition (smooth Fourier integral operators with smooth phase, smooth amplitude).

[NON_VERBATIM, per user's brief]: Khrennikov-Shelkovich symbol calculus on (Q_p)^n includes composition formulas — but for **multiplication operators in position** composed with **PDO in momentum**, not for **non-trivial automorphisms** of (Z/3^n)* acting as canonical maps. The Syracuse map T: ξ ↦ ξ · 2^{-1} on (Z/3^n)* is multiplication by a unit, hence permutation, hence its "canonical map" is a group automorphism on the dual.

The CRITICAL gap: the smooth Egorov theorem says "PDO_a ∘ F* = F* ∘ PDO_{a ∘ F} + lower order." The profinite analog should say: for f̂: ξ ↦ a(ξ) F[f](ξ) and T: x ↦ Tx group automorphism, then T* ∘ f̂ = ̂(a ∘ T) ∘ T* exactly. But the **off-diagonal-in-v cross-frequency terms** in Tao's recursion (R75-R77) DO NOT have this form — they are bilinear in μ̂_n(ξ · 2^{-v}) · μ̂_n*(ξ · 2^{-w}) with v ≠ w, which is **not the composition of a single PDO with a single canonical map** but rather a renewal-walk product (per C1_TAO_RECURSION_FORM).

## Recipe Component 5 — REPLACE escape functions with weights on discrete dual

### Verbatim findings

**Faure 2009** (`faure/…_pdfminer.txt` lines ~2400-2540): the escape function A_m(x,ξ) is built so that:
- A_m(x,ξ) ≤ const for (x,ξ) in trapped set Z = {(x,ξ) : |ξ| ≤ R}
- A_m(F(x,ξ))/A_m(x,ξ) ≤ C₂^|m| (slowly varying) for (x,ξ) in Z
- A_m(F(x,ξ))/A_m(x,ξ) ≤ 1/(E'(x))^{|m|} (geometric decrease) for (x,ξ) outside Z

The decisive bound on the principal symbol P^(n) in eq 39 uses these properties of A_m: the escape function gives geometric decay along expanding orbits outside the trapped set, and the trapped-set measure shrinks like (k/E_min)^n.

**Profinite analog needed:** weight w(ξ) on the discrete dual (Z/3^n)*^ such that:
- w(ξ) is bounded for "low frequency" ξ (small index in the dual)
- w(2^{-v} ξ mod 3^n) / w(ξ) ≤ C · (1/√3)^? for "high frequency" ξ (Faure 2009's prediction adapted to k=3 base)
- The level-n filtration provides the natural "weight order m" via the cyclic-group level

[NON_VERBATIM]: Kozyrev's basis ψ_{γjn} with eigenvalues p^{α(1-γ)} of D^α gives a candidate weight: w(ξ) = (1+|ξ|_p)^m. On (Z/3^n)*^ this becomes w(ξ) = 3^{m·d(ξ)} for d(ξ) = "3-adic depth" of ξ. The smoothness Faure exploits (A_m smooth as multiplicative function on T*S¹) is replaced by the **multiplicative structure of (Z/3^n)*^ under the Pontryagin pairing**.

**The PADE-observed structure** (from PADE_NUMERICAL_DISPOSITION):
- Leading singularity at |z| ≈ 1.57 (n=13) → spectral radius ≈ 0.637
- Faure 2009 prediction (k=3): 1/√3 ≈ 0.577
- Complex-conjugate pair, period 9.2, θ ≈ 0.68 rad

The escape function must produce this band structure on the discrete dual. The **trapped set Z** in Faure becomes, in the profinite analog, a **level-cap on the dual**: ξ such that |ξ|_3 ≤ 3^N for some level N depending on the iteration count. The geometric decrease outside Z translates to suppression of high-3-adic-frequency components by Plancherel mass (R75).

## Critical Surprises

### Surprise 1: Component 3 is essentially COMPLETE

Kozyrev's basis ψ_{γjn} + Vladimirov operator D^α with explicit eigenvalues p^{α(1-γ)} on L²(Q_p) is a **fully constructed p-adic PDO theory with semiclassical-like spectrum**. Khrennikov-Shelkovich extend it to (Q_p)^n. The user's brief assumes this is largely a gap; the literature has it in place. The hard work for Syracuse is reducing to this framework — not constructing it.

### Surprise 2: Component 5 is ALREADY 80% supplied by existing R75-R77 results

R75's Plancherel decomposition + R76's conservation law + R77's T_diag eigenstructure {0,1} on (1,-1), (1,4) **are exactly the data the escape-function construction needs**. The "trapped set Z" in Faure corresponds to the **low-frequency Plancherel mass** identified in R75 as the high-frequency 3∤ξ Fourier coefficients. The (1,4) eigenvector of T_diag is the **partial-captivity direction** in the profinite analog. What is missing is **the explicit weight function w(ξ)** and the verification that w(2^{-v}ξ)/w(ξ) ≤ const · (1/√3)^? on the relevant orbit set — this is a concrete computation, not a research monograph.

### Surprise 3: Components 1+6 transfer through Anker-Schapira-Trojan 2013, not directly

The PRIMARY mathematical infrastructure for Component 1 is NOT Cartwright-Kaimanovich-Woess 1994 (Poisson boundary) but **Anker-Schapira-Trojan 2013 / 2007** (heat-kernel asymptotic on Bruhat-Tits buildings) — which already produces the **right shape of asymptotic** (spectral radius ρ × polynomial decay × exponential phase) on a totally disconnected base.
