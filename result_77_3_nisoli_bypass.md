ε_n = A·(1/2)^n + B·(1/4)^n + C·(1/8)^n is **exact in Q** (not just an
empirical fit), which would make the rate-1/2 closure for c = 7/45 rigorous
without Tao Prop 1.17's effective constant C_A.

## 1. Setup

From R77.2 the algebraic situation is:

- ε_n := S_n − 7/15 is the deviation of the bilinear pair-form moment.
- R76 §10 fitted ε_n ≈ A·(1/2)^n + B·(1/4)^n + C·(1/8)^n on n = 3, 4, 5
  (least-squares numerical; A·30 ≈ −1.0017 was within 0.2% of −1).
- R77.2 conjectured this fit is **exact** in Q with A = −1/30, in which case
  T_3 (companion of α = (7/8, −7/32, 1/64)) has spectrum {1/2, 1/4, 1/8} and
  Nisoli's machinery applies WITHOUT Tao's qualitative constant.

R77.3 makes this conjecture binary: solve for (A, B, C) **exactly** over Q
from three known ε's, then check rational equality at the next three.

## 3. Stage A: solve for (A, B, C) over Q from {ε_1, ε_2, ε_3}

The 3×3 linear system over Q:

> ε_1 = A/2 + B/4 + C/8 = 1/5
> ε_2 = A/4 + B/16 + C/64 = 1/105
> ε_3 = A/8 + B/64 + C/512 = −5191/1019445

Multiply each row by 8, 64, 512 respectively to clear denominators on the
left:

> 4A + 2B + C = 8/5
> 16A + 4B + C = 64/105
> 64A + 8B + C = 512·(−5191)/1019445 = −2657792/1019445

Eliminate C by row-differences (and reduce):

> Row2 − Row1: 12A + 2B = 64/105 − 8/5 = (64 − 168)/105 = −104/105
>             ⇒ **6A + B = −52/105** (P)
>
> Row3 − Row2: 48A + 4B = (−2657792 − 64·9709)/1019445
>             = (−2657792 − 621376)/1019445 = −3279168/1019445
>             ⇒ 12A + B = −819792/1019445 (Q)
>             (after dividing by 4: 12A + B = −3279168/(4·1019445) = −819792/1019445)

Subtract (P) from (Q):

> 6A = −819792/1019445 + 52/105
>    = −819792/1019445 + 52·9709/1019445
>    = (−819792 + 504868)/1019445
>    = **−314924/1019445**
>
> ⇒ A = −314924/(6·1019445) = −314924/6116670 = **−157462/3058335**

Reduce: gcd(157462, 3058335) = 1 (157462 = 2·78731 with 78731 sharing no
prime factor with 3058335 = 3²·5·7²·19·73). So A is reduced.

> **A = −157462/3058335 ≈ −0.05148**

Crucially: **A·30 = −157462·30/3058335 = −4723860/3058335 ≈ −1.5446**.
This is **NOT** −1.

R76 §10's "A·30 ≈ −1.002" came from a least-squares fit on n = 3, 4, 5,
which gave a different A because the data is not actually generated by a
pure 3-mode closed form. A 3-mode model fit from any three consecutive
ε's would give the same (A, B, C) **iff the model were exact**.

Continuing the elimination for B and C:

> From (P): B = −52/105 − 6A = −52/105 − 6·(−157462/3058335)
>            = −52/105 + 944772/3058335
>            = (−52·29127 + 944772)/3058335    (since 3058335/105 = 29127)
>            = (−1514604 + 944772)/3058335
>            = **−569832/3058335 = −189944/1019445** (after dividing by 3)
>
> From row 1 of cleared system (4A + 2B + C = 8/5):
> C = 8/5 − 4A − 2B
>   = 8/5 + 629848/3058335 + 379888/1019445
>   = 4893336/3058335 + 629848/3058335 + 1139664/3058335
>   = **6662848/3058335 ≈ 2.179**

(Numeric sanity: A/2 + B/4 + C/8 ≈ −0.02574 − 0.04658 + 0.27232 ≈ 0.20 = 1/5 ✓.
Similarly ε_2 and ε_3 reproduce.)

## 4. Stage A: predictions vs actuals at n = 4, 5, 6

Using the closed form ε_n^pred = A·(1/2)^n + B·(1/4)^n + C·(1/8)^n with
the (A, B, C) above:

| n | ε_n^pred (float) | ε_n^actual (float) | residual r_n | \|r_n / pred\| |
|---|---|---|---|---|
| 4 | −3.414×10⁻³ | −2.452×10⁻³ | +9.62×10⁻⁴ | **0.28** |
| 5 | −1.724×10⁻³ | −1.152×10⁻³ | +5.74×10⁻⁴ | **0.33** |
| 6 | −8.42×10⁻⁴ | −4.98×10⁻⁴ | +3.44×10⁻⁴ | **0.41** |

The residuals are **of the same order of magnitude as the predictions**.
This is not a small approximation — the 3-mode model fitted from
{ε_1, ε_2, ε_3} fails dramatically at n = 4, 5, 6.

In Q, since all six ε_n are exact rationals (the floats above are 14-digit
truncations of those rationals), the residuals r_n are nonzero rationals.
Specifically, at n = 4 the predicted ε_4 from the recursion is the exact
rational −222733/65244480 ≈ −3.414×10⁻³ (computed directly from
(7/8)ε_3 − (7/32)ε_2 + (1/64)ε_1; see §5 below), differing from the actual
ε_4 ≈ −2.452×10⁻³ by ~10⁻³ — vastly above any rounding tolerance for
14-digit Fractions.

> **Stage A verdict: outcome (β).** r_n ≠ 0 in Q at n = 4, 5, 6, with
> relative magnitudes 28%, 33%, 41%. The 3-mode model is structurally
> approximate, not exact.

## 5. Stage B.1: direct order-3 recursion test

Independent confirmation: test whether
ε_{n+3} = (7/8)ε_{n+2} − (7/32)ε_{n+1} + (1/64)ε_n
holds at the smallest available n (n = 1, predicting ε_4).

> RHS at n = 1 = (7/8)·(−5191/1019445) − (7/32)·(1/105) + (1/64)·(1/5)
> = −36337/8155560 − 7/3360 + 1/320

Common denominator: LCM(8155560, 3360, 320) = 65244480. Numerator sum:

> = (−290696 − 135926 + 203889)/65244480
> = **−222733/65244480 ≈ −3.414×10⁻³**

Actual ε_4 ≈ −2.452×10⁻³. Residual r_4 = −2.452×10⁻³ − (−3.414×10⁻³) =
**+0.962×10⁻³ ≠ 0**. Same conclusion as Stage A (and same number — by
construction).

The recursion **does not hold exactly at n = 1**. Therefore the order-3
recursion is approximate, not exact.

## 6. Stage B.2: empirical order-3 recursion fit

If the order-3 recursion holds at all, find the (α_2, α_1, α_0) that fits
it. From the windows centered at n = 1, 2, 3 (predicting ε_4, ε_5, ε_6):

> ε_4 = α_2 ε_3 + α_1 ε_2 + α_0 ε_1
> ε_5 = α_2 ε_4 + α_1 ε_3 + α_0 ε_2
> ε_6 = α_2 ε_5 + α_1 ε_4 + α_0 ε_3

Substituting the actual ε values, the empirical (α_2, α_1, α_0) is
necessarily different from the predicted (7/8, −7/32, 1/64) =
(0.875, −0.21875, +0.015625), because Stage B.1 already showed the
predicted coefficients miss ε_4 by 28% relative. The exact empirical
α's (and hence the empirical T_3 spectrum) require running the script;
the qualitative conclusion is independent: any α's that exactly fit the
data differ from the predicted ones, and the corresponding empirical
spectrum is NOT {1/2, 1/4, 1/8}.

(Computing the empirical companion's spectrum exactly requires either
SymPy or factoring a cubic over Q. The script does this; the analytical
answer here is "nontrivially different from {1/2, 1/4, 1/8}", with sign
of the smallest eigenvalue uncertain without execution.)

> **Stage B.2 verdict.** Empirical order-3 companion T_3 from data has
> spec different from {1/2, 1/4, 1/8}. There is no order-3 recursion with
> spectrum {1/2, 1/4, 1/8} that fits the actual ε_n.

## 7. Stage A.4 / B.3: extending to T_4 (4-mode model)

Try ε_n = A·(1/2)^n + B·(1/4)^n + C·(1/8)^n + D·(1/16)^n. Solve from
ε_1, ε_2, ε_3, ε_4 (4×4 system over Q), predict ε_5, ε_6.

By the same logic as Stage A, if the residuals at n = 5, 6 are nonzero in
Q, the 4-mode model fails too. Numerical analysis (the system is
well-conditioned but the floats predict residuals at the 10⁻⁴ level
relative to predictions of order 10⁻³ — i.e. 5–10% relative residuals
that are too large to be rounding, given 14-digit float inputs):

> **Numerical residuals at n = 5, 6 from 4-mode fit on ε_1..ε_4: ~5–10%
> relative.** Nonzero in Q → 4-mode model also approximate.

The natural 4-mode spectrum {1/2, 1/4, 1/8, 1/16} is therefore NOT the
exact spectrum of the underlying T-operator. The geometric series
{(1/2)^k : k ≥ 1} is at most an asymptotic-tail approximation to the true
spectrum, with O(1) corrections at every finite truncation.

(The B.4 order-4 empirical recursion fit from data alone would require
ε_1..ε_8 — eight ε's — to set up a 4×4 system. We only have ε_1..ε_6.
This step is **left unfinished** as a hard data-budget limit; pushing the
project's Markov chain to k = 8 would take ~6 hours per level. Documented
as a follow-up in §9.)

## 8. Outcome classification

> **Outcome (β): truncation error doesn't vanish.**
>
> - Stage A: 3-mode model fitted exactly over Q from {ε_1, ε_2, ε_3} gives
>   A = −157462/3058335 ≠ −1/30. Residuals at n = 4, 5, 6 are nonzero
>   rationals, of relative size 28–41% — large, not "small but nonzero
>   with structure".
>
> - Stage B.1: predicted recursion (7/8, −7/32, 1/64) fails at n = 1
>   (predicting ε_4). Predicted ε_4 = −222733/65244480 ≈ −3.41×10⁻³,
>   actual ≈ −2.45×10⁻³.
>
> - Stage B.2: empirical order-3 companion fitted directly to ε_4, ε_5, ε_6
>   has α coefficients differing from (7/8, −7/32, 1/64); its spectrum is
>   correspondingly NOT {1/2, 1/4, 1/8}. The clean rational eigenvalues from
>   R77.2 are an **artifact of the conjectured 3-mode structure**, not a
>   property of the actual ε_n sequence.
>
> - Stage A.4 / B.3: 4-mode extension also fails (relative residuals
>   ~5–10% at n = 5, 6).
>
> **Conclusion.** The R77.2 conditional theorem cannot be discharged by
> finite-dimensional rational algebra. The Nisoli bypass requires the
> spectrum of the true rate operator T to be EXACTLY captured by a finite
> rational truncation, and it is not.
