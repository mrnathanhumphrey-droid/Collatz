# fluid_dynamics — Transfer Operators / Anisotropic Banach Spaces / Anosov Flows

Goal of this set: read with the question "does the analytical infrastructure for *find slow modes in a function space tuned to the dynamics* apply to the discrete (Z/3^k)* framework?"

Fetched 2026-05-05. All sources are free legal: arXiv, journal-author copies, or annals.math.princeton.edu open archive.

## Reading order (suggested for the question)

1. **`baladi_2003_dynamical_zeta_arxiv.pdf`** — gentle entry to the dynamical-zeta-function program; defines the analytic infrastructure (transfer operator, anisotropic spaces, Ruelle resonance spectrum).
2. **`baladi_2014_quest_anisotropic_banach_arxiv.pdf`** — survey of how anisotropic Banach spaces evolved; this is the meta-question of "what function space lets the operator have nice spectrum?", directly analogous to the (Z/3^k)* question.
3. **`liverani_notes_ravello.pdf`** OR `liverani_notes_barcellona.pdf` — Liverani's own pedagogical re-presentation; covers the 1995 framework + later refinements.
4. **`baladi_tsujii_2007_anisotropic_arxiv.pdf`** — concrete realization: anisotropic Hölder/Sobolev spaces for hyperbolic diffeomorphisms.
5. **`faure_sjostrand_2011_anosov_resonances_arxiv.pdf`** — flow analog with Weyl-law-style upper bound on resonance density.
6. **`giulietti_liverani_pollicott_2013_anosov_zeta_annals.pdf`** — capstone: spectral picture for Anosov flows via the Liverani-Tsujii program.
